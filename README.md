# Sistemas Embarcados - ADS

Trabalho da disciplina de **Sistemas Embarcados** do curso de **Análise e Desenvolvimento de Sistemas (ADS)** da **Universidade Federal do Ceará (UFC)**.

## Conteúdo

O projeto reúne implementações em Verilog desenvolvidas nas práticas da disciplina:

- **Prática 1:** portas lógicas AND, OR, XOR, XNOR e NOT, com seus circuitos e plots de simulação;
- **Prática 2:** multiplexador;
- **Prática 3:** registrador;
- **Prática 4:** máquina de estados finitos para controle de uma torneira.

## Estrutura

```text
Prática1/
  *.v
  *.digitaljs
  images/
Prática2/
  mux_porta.v
Prática3/
  *.v
  *.digitaljs
Prática4/
  *.v
  *.digitaljs
```

Os arquivos `.v` contêm o código Verilog e os arquivos `.digitaljs` podem ser abertos no DigitalJS para visualizar e simular os circuitos.
